Scales

The Scales page shows fingering for every scale and arpeggio in all 12 keys, with interactive piano keyboards for both hands.

Choosing a Scale

Tap any scale type at the top — Major, Nat Min, Harm, Melodic, Maj Arp or Min Arp. Then tap a key from the grid to select your root note.

Scale Types

  • Major — standard major scale
  • Nat Min — natural minor scale
  • Harm — harmonic minor, raised 7th
  • Melodic — melodic minor, separate ascending and descending views
  • Maj Arp — major arpeggio over 2 octaves
  • Min Arp — minor arpeggio over 2 octaves

Relative & Parallel

Below the key selector, the Relative and Parallel buttons jump you to the related scale instantly. From C Major, Relative takes you to A Natural Minor. Parallel takes you to C Minor.

Key Up

The Key ↑+3 button shifts the current scale up 3 semitones. Press it repeatedly to cycle through keys. When a scale is playing in loop mode, the change waits until the end of the current loop before switching — no interruption.

Changing Key While Looping

While a scale is looping you can queue changes without stopping playback:

  • Tap any tonic key — queues a key change at the end of the current run. The tapped key glows amber while waiting.
  • Tap a scale type (Major, Harm etc) — marks it as pending without changing the display. Then tap a tonic key to queue that combination.
  • Tap Relative or Parallel — queues the related scale change the same way.
  • Tap the currently playing key — ignored unless a different scale type is pending.

The currently playing key stays highlighted in its colour. The newly queued key glows dimly amber so you can see both at once.

Playback

  • Press ▶ to play the scale at the current tempo
  • Press the loop button to keep repeating
  • Choose Both, RH or LH to hear one or both hands
  • Tap the BPM number to type a specific tempo
  • Scroll Sync keeps both keyboards scrolled together

Tap any highlighted key on the keyboard to hear that individual note.

Tempo Trainer

The Tempo Trainer automatically increases the tempo as you practise — a classic exam preparation technique. Configure it below the transport controls.

  • Start BPM — the tempo training begins at. Hold + or − to scroll quickly.
  • Target BPM — training ends when this is reached
  • Increment BPM — how much the tempo increases each step
  • Every N loops — how many loops to complete at each tempo before stepping up

Press ▶ Start Trainer to begin. The tempo increments automatically after each set of loops. Press ■ Stop Trainer at any time. Once the target tempo is reached, "Goal reached!" flashes on screen and the scale keeps looping freely at that tempo until you stop.

Metro Only

Silences the piano and plays only metronome clicks. The keys still flash showing which note to play — useful for practising technique without the sound guiding your fingers.

Count-in

Adds a metronome count before the scale starts. Choose 1, 2 or 3 bars. The count displays as a large number overlay (1, 2, 3, 4) and Go! flashes green when the scale begins.

Training Info

A slim bar appears below the keyboards during a training session. Set it to show Off, BPM, Time (countdown) or Both. The countdown ticks in real time and can be switched on or off mid-session — it will always be accurate.

Scale Cycle

Extends the Tempo Trainer to rotate through multiple keys automatically. Instead of repeating one scale, the trainer cycles through your selected keys — playing each one the set number of times before moving on, then repeating the round at the next tempo step.

Setting up Scale Cycle

  • Toggle Enable Scale Cycle in the Tempo Trainer panel
  • Tap ⟳ to open the key picker
  • Choose a scale type — all keys in the cycle use this type
  • Tap keys to include them — tap again to deselect
  • Choose Chromatic or Fifths order for the playback sequence

With 3 keys and Every N loops set to 2: C×2, D×2, E×2 at the first tempo, then all three again at the next tempo, and so on.

Key Change Mode

  • Full Scale (default) — completes every note including the final root before switching. The most natural way to practise.
  • Smooth Transition — skips the final note and plays the first note of the next key in its place. Seamless, no gap.

Pause Between Keys

Available in Full Scale mode only. Adds a single beat gap with a metronome click between key changes — giving you a moment to prepare. Enabled by default.

For exam preparation across all keys: select all 12 keys in fifths order, set your start and target BPM, Every N loops to 2, enable Count-in and Pause Between Keys. The app works through every key systematically, getting faster each round.

Chords

The Chords page shows every chord in the current key on a scrollable piano keyboard, and lets you loop chord progressions.

Chord Display

The keyboard highlights the notes of each chord as you tap them. The chord name and Roman numeral are shown above.

Chord Progressions

Scroll down to see a library of common progressions — Pop, Blues, Jazz, Classical and more. Each has a play and loop button.

  • ▶ plays the progression once
  • ↻ loops it continuously — press again to play out the current loop then stop
  • Tap the BPM number to set your tempo

Key Changes While Looping

While a progression is looping, press the Key ↑+3, Relative or Parallel buttons to queue a key change. The change fires cleanly at the end of the current loop with no interruption.

The Relative button cycles between a major key and its relative minor — great for practising both together.

Pads

The Pads page is a performance playground with three modes: Chord, Drum and Melody.

Switching Modes

Tap the mode selector button at the top to switch between Chord, Drum and Melody pads.

8 or 12 Pads

The 8⊞ button toggles between 8 and 12 pads in all three modes. 12 pads extends the range with additional notes and sounds.

Chord Pads

Eight or twelve chord pads laid out in the key you select. Hold multiple pads at once to combine chords.

  • Tap the key button to change key
  • Maj/Min toggles between major and minor chord qualities
  • Chord Pattern selects the progression playing in the background
  • ▶ starts and stops the chord loop
  • ↻ toggles looping — press while looping to play out the bar then stop
  • ♫ Arp switches to arpeggio mode
  • ↑ Key queues a key change at the next bar 1
  • ↺ Key resets to the original key

Drum Pads

Eight or twelve drum pads with synthesised sounds. Tap to trigger, or use the auto pattern buttons.

  • Simple, Disco, Rock, Breakdown — auto patterns that switch cleanly on beat 1
  • Fill — triggers a drum fill on the next bar
  • ▶ starts and stops the drum loop
  • ⇄ Move — rearrange the pads into any order
  • 12 pads adds Rim, Cowbell, Shaker and Ride sounds

Melody Pads

Eight or twelve pads mapped to the notes of the current scale. Play melodies over the chord and drum loops.

  • Pads are colour-coded by note
  • Swipe between pads to slide between notes
  • Multiple fingers play multiple notes simultaneously
  • Maj/Min switches the scale quality — queued at beat 1 when loops are running
  • ♫ Arp plays notes as arpeggios instead of sustained chords
  • ↑ Key queues a key change at beat 1

Layering All Three Together

All three layers can run simultaneously. Start a drum pattern, add a chord loop, then play melody on top. Drums snap to beat 1 automatically when added to a running loop.

Press a new drum pattern button while playing to queue it — it switches cleanly on the next bar 1, never mid-bar.

Fingering Editor

The Fingering page shows recommended fingering for the current scale on both hands, and lets you customise it to suit your own technique.

Viewing Fingering

Select any scale from the grid at the bottom of the page. The keyboards update to show fingering numbers on each highlighted key.

Editing Fingering

  • Tap a key — cycles the finger number 1→2→3→4→5→1
  • Input boxes — type directly into the numbered boxes below each keyboard for precise entry

Both methods stay in sync — tap a key and the input box updates, type in a box and the keyboard updates.

Saving & Restoring

  • Press Save to store your changes — they persist between sessions
  • Restore this scale — resets just the current scale to its built-in default
  • Restore ALL scales — resets every scale back to defaults

For Melodic Minor, switch between ASC and DESC on the Scales page to edit ascending and descending fingerings separately.

Metronome

A full-featured metronome with visual beat display, tap tempo and multiple sound options.

Basic Use

  • Press ▶ to start and stop
  • Drag the tempo slider or tap the BPM number to type a value directly
  • Use the −10, −5, +5, +10 buttons for quick adjustments — hold any button to scroll continuously
  • Tap Tempo — tap the button repeatedly in time to set tempo by feel

Time Signatures

Choose from 2/4, 3/4, 4/4 or 6/8. Or tap Custom to enter any time signature — 5/4, 7/8, 11/8, whatever you need.

No Accent

Turns off the beat 1 accent so every click sounds identical.

Sound Options

  • Sine — clean electronic click
  • Wood — wooden block sound
  • Rimshot — sharp rimshot crack
  • Loud — louder version for noisy environments

Synth

The Synth panel controls the sound character of the piano keyboard and scale playback. Tap the wave icon (∿) in the top right of any page to open it.

Wave Type

  • Sine — pure, smooth tone. Closest to a clean piano or flute
  • Triangle — slightly brighter than sine, soft and warm
  • Sawtooth — rich and bright, full of harmonics. Closest to strings or brass
  • Square — hollow and buzzy, classic synth or clarinet character

Sliders

  • Attack — how quickly the note reaches full volume. Short = punchy, Long = swells in gradually
  • Decay — how long the note rings after the peak. Short = staccato, Long = notes ring on
  • Harmonics — adds upper overtones to thicken the sound. Higher = brighter and more complex
  • Reverb — adds room ambience. Low = dry and close, High = spacious and distant
  • Noise Mix — blends in a noise layer for a breathier, more organic texture

For a piano-like sound try Sine wave with short attack, medium decay, low harmonics and a touch of reverb.

Settings

Open settings by tapping the gear icon ⚙️ in the top right corner of any page.

Appearance

  • Dark — default dark theme
  • Midnight — deeper, richer dark theme with true blacks
  • Cream — warm off-white light theme
  • Light — clean bright white theme

Key Highlight Palette

Six colour palettes for the left and right hand highlights on the piano keyboards.

Haptic Feedback

Toggles vibration on keyboard taps.

Display

  • Show note names on keys — toggles the C D E F G A B labels below every piano key across the whole app
  • Dark piano keys — switches the piano keyboard to a dark colour scheme. Purely visual — scale highlighting and fingering numbers are unaffected.
  • Bluetooth delay — delays the keyboard flash to compensate for Bluetooth headphone latency. Adjust in 10ms steps until visuals sync with what you hear. Typical starting point: 150ms for standard Bluetooth, 100ms for AAC, 80ms for aptX.

Playback

  • Keep playing when screen locks — keeps the metronome or drum loops running with the screen locked

Defaults

  • Default Key — which key is selected on launch
  • Default Scale Type — which scale type is selected on launch
  • Default Pad Mode — whether Pads opens on Chord, Drum or Melody
  • Default Pad Count — whether pads start with 8 or 12 pads
