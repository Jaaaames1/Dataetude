Fingering Editor

View and customise fingering for every scale

The Fingering page shows recommended fingering for the current scale on both hands, and lets you customise it to suit your own technique.

Viewing Fingering

Select any scale from the grid at the bottom. The keyboards update to show finger numbers on each highlighted key.

Editing Fingering

Two ways to edit — both stay in sync with each other:

  • Tap a key — cycles the finger number 1→2→3→4→5→1
  • Input boxes — type directly into the numbered boxes below each keyboard

Saving

Press Save to store your changes. They persist between sessions so your custom fingerings are always there when you return.

Restoring Defaults

  • Restore this scale — resets just the current scale to its built-in default
  • Restore ALL scales — resets every scale back to defaults

For Melodic Minor, switch between ASC and DESC on the Scales page to edit ascending and descending fingerings separately.
