Songs

The Songs page is your library. Every song you create lives here.

Creating a Song

Tap the + button to create a new song. It is named automatically with an incrementing title — rename it any time by tapping the title inside the editor.

Search and Sort

  • Search by title using the search bar at the top
  • Sort by date created, date modified or title

Deleting Songs

Swipe a song left or use the long-press menu to delete. Deletions are permanent — use backup if you want to keep a copy.

Lyric Editor

The editor is section-based. Each section has a type (Verse, Chorus, Bridge, Pre-Chorus, Outro or Custom) and a text area for your lyrics.

Adding Sections

Tap the + Section button at the bottom of the editor to add a new section. Choose the section type from the picker.

Editing Sections

  • Tap inside any section to start typing
  • Drag the handle at the bottom of a section to resize it
  • Tap the section header to rename, duplicate, move up, move down or delete

Undo

Tap the undo button in the toolbar to reverse the last structural change. Text edits within a section use the standard system undo.

Word and Line Counts

Each section shows a live word and line count. The total for the whole song is shown at the bottom of the editor.

View Mode

Switch to View mode to see a clean read-only version of your lyrics. Supports single and double column layouts, zoom and fullscreen.

PDF Export

Tap the export button to generate a formatted PDF of the current song. The PDF opens in your device share sheet so you can save, print or send it anywhere.

Rhyme Finder

Type any word into the search box to get rhyme suggestions. Results are grouped by syllable count so you can quickly find the right fit for your line.

Definitions

Tap any word to see its definitions, organised by part of speech. Useful for checking a word means what you think before committing to it.

Word Actions

Tap and hold any result word to copy it, or to search for rhymes of that word in turn.

The Rhyme Finder uses the Datamuse API and requires an internet connection.

Notes

The Notes page holds free-form tiles for anything that does not belong inside a specific song — ideas, references, fragments, reminders.

Creating Notes

Tap + to add a new note tile. Tap inside the tile to edit. Notes are saved automatically.

  • Long press a note to delete it
  • Notes are global — not tied to any specific song

Settings and Backup

Themes

Four themes: Midnight, Dark, Cream and Light — matching Piano Scales Lab.

Layout Presets

Choose from editor layout presets that adjust font size, line height and section spacing to suit your working style.

Backup

  • Tap Export Backup to save a backup file via the share sheet
  • Tap Import Backup to restore from a previously saved backup file

Back up regularly — deleting the app removes all local data. The backup file is the only copy outside your device.
