Scales & Arpeggios

Playing scales in every key with correct fingering

The Scales page shows fingering for every scale and arpeggio in all 12 keys, with interactive piano keyboards for both hands.

Choosing a Scale

Tap any scale type at the top — Major, Nat Min, Harm, Melodic, Maj Arp or Min Arp. Then tap a key from the grid to select your root note.

Scale Types

  • Major — standard major scale
  • Nat Min — natural minor scale
  • Harm — harmonic minor, raised 7th
  • Melodic — melodic minor with separate ascending and descending views
  • Maj Arp — major arpeggio over 2 octaves
  • Min Arp — minor arpeggio over 2 octaves

Relative & Parallel

The Relative and Parallel buttons jump you to the related scale instantly. From C Major, Relative takes you to A Natural Minor. Parallel takes you to C Minor.

Key Up

The Key ↑+3 button shifts the scale up 3 semitones. When playing in loop mode, the change waits until the end of the current loop — no interruption.

Changing Key While Looping

While a scale is looping you can queue changes without stopping playback:

  • Tap any tonic key — queues a key change, fires at the end of the current run. The tapped key glows amber while waiting.
  • Tap a scale type (Major, Harm etc) — marks it as pending without changing the display. Then tap a tonic key to queue that combination.
  • Tap Relative or Parallel — queues the related scale change the same way.
  • Tap the currently playing key — ignored unless a different scale type is pending.

The currently playing key stays highlighted in its colour. The newly queued key glows dimly amber so you can see both at once.

Playback

  • Press ▶ to play the scale at the current tempo — starts immediately
  • Press the loop button to keep repeating — also starts immediately if not already playing
  • Choose Both, RH or LH to hear one or both hands
  • Tap the BPM number to type a specific tempo
  • Scroll Sync keeps both keyboards scrolled together

Tap any highlighted key on the keyboard to hear that individual note.

Tempo Trainer

The Tempo Trainer section below the transport automatically increases the tempo as you practise — a classic exam preparation technique.

  • Start BPM — the tempo training begins at. Hold + or − to scroll quickly.
  • Target BPM — training ends when this is reached
  • Increment BPM — how much the tempo increases each step (+5 default)
  • Every N loops — how many loops to complete at each tempo before stepping up (2 default)

Press ▶ Start Trainer to begin. The tempo increments automatically and current progress is shown in the status line. Press ■ Stop Trainer at any time — this also stops playback. Once the target is reached, "Goal reached!" flashes on screen and the scale keeps looping freely at the target tempo until you stop.

Metro Only Mode

Toggle Metro only in the Tempo Trainer to practise silently. The piano keys still light up showing which note to play and what finger to use, but instead of piano sounds you hear only metronome clicks. Useful for developing physical technique without letting the sound guide your fingers.

Count-in

Enable Count-in in the Tempo Trainer to get a metronome count before the scale starts. Choose 1, 2 or 3 bars of count-in. The count displays as a large overlay number (1, 2, 3, 4) and Go! flashes in green the moment the scale begins.

Training Info

A slim bar appears below the keyboards during a training session showing live session information. Choose what to display:

  • Off — nothing shown
  • BPM — current tempo, updates each time it increments
  • Time — countdown to the end of the session, ticking down in real time
  • Both — current BPM and countdown side by side

The bar can be switched on or off at any point — even mid-session — and the countdown will always be accurate to where you are in the session.

Scale Cycle

Scale Cycle extends the Tempo Trainer to automatically rotate through multiple keys during a session. Instead of repeating the same scale, the trainer cycles through whichever keys you select — at each tempo step, every selected key is played the set number of times before moving on.

Setting up Scale Cycle

  • Toggle Enable Scale Cycle in the Tempo Trainer panel
  • Tap the ⟳ button to open the key picker
  • Select a scale type for the cycle — all keys will use this type
  • Tap any keys to include them — tap again to deselect. All 12 can be selected.
  • Choose Chromatic or Fifths order to determine the sequence keys play in

With 3 keys selected and Every N loops set to 2, the trainer plays each key twice before moving to the next — C×2, D×2, E×2 — then repeats at the next tempo step.

Key Change Mode

Controls how the app transitions between keys:

  • Full Scale (default) — completes every note of the scale including the final root note before switching to the next key. The most natural way to practise.
  • Smooth Transition — skips the final note of each scale and plays the first note of the next key in its place. Creates a seamless join with no gap.

Pause Between Keys

Available in Full Scale mode only. Adds a single beat gap with a metronome click between each key change — giving you a moment to prepare before the next scale begins. Enabled by default.

For exam preparation across all keys: select all 12 keys in fifths order, set Start BPM to a comfortable speed, Target BPM to your exam tempo, Every N loops to 2, enable Count-in and Pause Between Keys. The app works through every key systematically, getting faster with each round.
