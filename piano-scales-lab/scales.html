Piano Scales Lab

Scales & Arpeggios

Playing scales in every key with correct fingering

The Scales page shows fingering for every scale and arpeggio in all 12 keys, with interactive piano keyboards for both hands.

Choosing a Scale

Tap any scale type at the top of the sidebar, then tap a key from the grid below it to select your root note.

Scale Types

  • Major — standard major scale over 2 octaves
  • Nat Min — natural minor scale over 2 octaves
  • Harm — harmonic minor, raised 7th, over 2 octaves
  • Melodic — melodic minor with separate ascending and descending views
  • Maj Arp — major arpeggio over 2 octaves
  • Min Arp — minor arpeggio over 2 octaves
  • Maj Pent — major pentatonic scale over 1 octave
  • Min Pent — minor pentatonic scale over 1 octave
  • Chromatic — all 12 semitones over 2 octaves

Relative and Parallel

The Relative and Parallel buttons jump you to the related scale instantly. From C Major, Relative takes you to A Natural Minor. Parallel takes you to C Minor. Both work for pentatonic scales — C Major Pentatonic relative is A Minor Pentatonic. Not available for Chromatic.

Key Up

The Key +3 button shifts the scale up 3 semitones. When playing in loop mode, the change waits until the end of the current loop.

Changing Key While Looping

  • Tap any tonic key — queues a key change at the end of the current run. The tapped key glows amber while waiting.
  • Tap a scale type (Major, Harm etc) — marks it as pending. Then tap a tonic key to queue that combination.
  • Tap Relative or Parallel — queues the related scale change the same way.

The currently playing key stays highlighted in its colour. The newly queued key glows amber so you can see both at once.

Playback

  • Press ▶ to play the scale at the current tempo
  • Press the loop button to keep repeating
  • Choose Both, RH or LH to hear one or both hands
  • Tap the BPM number to type a specific tempo
  • Scroll Sync keeps both keyboards scrolled together

Tap any highlighted key on the keyboard to hear that individual note.

Tempo Trainer

Automatically increases the tempo as you practise.

  • Start BPM — tempo training begins here. Hold + or minus to scroll quickly.
  • Target BPM — training ends when this is reached
  • Increment BPM — how much the tempo increases each step
  • Every N loops — how many loops to complete at each tempo before stepping up

Press Start Trainer to begin. Once the target is reached, Goal reached! flashes and the scale keeps looping freely until you stop.

Metro Only Mode

Toggle Metro only to practise silently. The keys still flash showing which note to play, but you hear only metronome clicks.

Count-in

Enable Count-in to get a metronome count before the scale starts. Choose 1, 2 or 3 bars. Go! flashes green when the scale begins.

Training Info

A slim bar below the keyboards during a session. Select BPM, Time countdown or Next Scale — any combination. The countdown is always accurate, even if switched on mid-session.

Scale Cycle

Extends the Tempo Trainer to rotate through multiple keys automatically at each tempo step.

Setting up Scale Cycle

  • Toggle Enable Scale Cycle in the Tempo Trainer panel
  • Tap the cycle button to open the key picker
  • Choose a scale type for the cycle — all keys use this type
  • Tap keys to include them — tap again to deselect
  • Choose Chromatic or Fifths order for the playback sequence

With 3 keys and Every N loops set to 2: C x2, D x2, E x2 at the first tempo, then all three again at the next tempo.

Key Change Mode

  • Full Scale (default) — completes every note including the final root before switching.
  • Smooth Transition — skips the final note and plays the first note of the next key in its place.

Pause Between Keys

Full Scale mode only. Adds a single beat gap with a metronome click between key changes. Enabled by default.

For exam prep across all keys: select all 12 in fifths order, set your start and target BPM, Every N loops to 2, enable Count-in and Pause Between Keys. The app works through every key systematically, getting faster each round.
